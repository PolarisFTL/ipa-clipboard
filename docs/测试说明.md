# 测试说明

版本：**v1.0.1**。应用已在 Windows 11 x64（10.0.26200）实际构建和运行；SDK 10.0.402，内嵌 .NET 与 Windows Desktop Runtime 10.0.13。

## 已执行

- Release 构建、SelfContained 单文件发布成功，编译0警告、0错误。
- 确认 EXE 为 x64（PE 0x8664）、Windows GUI 子系统（2），不会创建控制台窗口。
- 故意设置无效 DOTNET_ROOT、从 PATH 移除 SDK 后直接启动发布 EXE，自测通过；标准系统 .NET 安装路径中没有 dotnet.exe。
- **54项自动检查通过**：英语48项、完整IPA分类、Unicode数据、实际剪贴板写入和回读、三种格式、多字符与组合符号、占用重试、搜索、收藏/历史、配置恢复、字体覆盖、置顶和模式切换、屏外恢复、原生标题栏命中测试。
- EXE 退出后，由父进程实际读取系统剪贴板，确认 `θðʃʒŋɜːaɪ̃` 仍然保留。
- 真实单击 `/ʃ/` 后，独立进程回读为 `ʃ`（U+0283）；在新建 Word 文档中实际按 Ctrl+V，文档文本确认为 `ʃ`。Word 检查在标题栏拖动修正前完成，修正未改变剪贴板代码。
- 真实鼠标拖动标题栏空白区域，窗口位置发生变化；右键收藏后出现星标，偏好实际落盘。
- 实际点击迷你按钮，界面缩小并隐藏示例词；恢复完整模式成功。
- 对最终1.0.1重复启动两次：两个新进程退出，原主进程保持，始终只有一个窗口。

## 界面检查

已检查完整440×570、迷你320×420、最小完整300×360的布局。音标区可以滚动，没有发现控件重叠、关键音标截断或缺字方块。

README的例图来自真实WPF界面渲染。另完成100%、125%、150%、200%的渲染检查；后面三档是 RenderTargetBitmap 的不同DPI输出，**不是将系统显示缩放逐档切换后的实机测试**。
