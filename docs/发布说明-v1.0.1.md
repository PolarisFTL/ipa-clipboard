# IPA 音标助手 v1.0.1

一个放在桌面上的音标小工具：**双击 EXE → 单击音标 → Ctrl+V 粘贴**。

适合英语备课、论文写作、课件和日常语言学习。默认置顶，也可切换迷你面板。

## 下载哪个文件

- **IPA音标助手.exe**：下载后直接双击，约61.89 MiB。
- **IPA-Clipboard-v1.0.1-win-x64.zip**：包含EXE、中文使用说明和许可文件，解压后运行。
- **SHA256SUMS.txt**：文件校验值。

不需要安装Python、Java、Node.js或.NET Runtime，也不需要管理员权限。面向兼容.NET 10的Windows 10/11 x64，离线运行。

## 主要功能

- 英语教材48项、完整IPA175项、常用符号9项；共232分类条目、194种不同复制内容。
- 单击复制Unicode文本；支持纯音标、斜杠和方括号。
- 实时搜索、收藏、最近12项、置顶、迷你模式、偏好记忆和单实例。
- 重音与附加符号原样复制，虚线占位圆圈不会进入剪贴板。
- 已修复标题栏空白区域无法拖动，采用Windows原生拖动机制。
