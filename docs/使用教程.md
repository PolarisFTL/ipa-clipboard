# IPA 音标助手：中文使用教程

## 1. 下载与启动

打开 [最新版下载页](https://github.com/PolarisFTL/ipa-clipboard/releases/latest)，在 **Assets / 附件** 中选择：

- **`IPA-Clipboard.exe`**：单文件，下载后直接双击。
- **`IPA-Clipboard-v1.0.1-win-x64.zip`**：含 EXE、使用说明和许可文件，解压后双击其中的 **`IPA音标助手.exe`**。

两种下载运行的是同一程序。GitHub 单文件附件使用英文名以保持下载文件名稳定；也可以自行将它重命名为 `IPA音标助手.exe`，不影响运行。

普通使用不需要下载 GitHub 自动打包的 `Source code`，也不用安装开发工具或 .NET Runtime。支持兼容 .NET 10 的 Windows 10/11 x64；不提供 macOS、Linux 或 Windows ARM 原生版本。

首次启动可能稍慢，因为自包含 EXE 需要在用户临时目录提取内置原生库。程序以普通用户权限运行。

## 2. 复制第一个音标

![完整模式界面](images/main.png)

1. 在“英语常用”标签中找到需要的音标。
2. 用鼠标**单击一次**，例如 `/æ/`。不需要 Ctrl+C 或额外确认。
3. 底部出现“✓ 已复制 /æ/”。
4. 切回 Word、PPT、WPS、聊天输入框或其他文本编辑器，按 **Ctrl+V**。

默认复制的内容是纯文本 `æ`，不是图片，也不是音标名称。关闭音标助手后，最后一次复制的内容仍可粘贴。

## 3. 切换复制格式

分类栏右侧的“复制为”可以选择：

| 选择 | 单击 `/ʃ/` 后复制 | 单击 `/aɪ/` 后复制 |
|---|---|---|
| 纯音标 | `ʃ` | `aɪ` |
| /音标/ | `/ʃ/` | `/aɪ/` |
| [音标] | `[ʃ]` | `[aɪ]` |

重音、时长、声调和附加符号会原样复制，不额外套上斜杠或方括号。界面显示的斜杠与当前复制格式是两件事，复制结果以该选项为准。

## 4. 用搜索快速定位

在顶部搜索框输入内容，当前标签会立即筛选，无需按 Enter。

| 输入 | 可以找到 |
|---|---|
| `ship` | `/ʃ/` |
| `think` | `/θ/` |
| `鼻音` | 鼻音分类中的相关条目 |
| `ɜː` | 对应长元音 |
| `schwa` | 中央元音 `ə` |

搜索作用于**当前标签和当前分类**。找不到时可先选择“全部分类”，或切换到“完整 IPA”。点击搜索框右侧的 `×` 清空关键词。

## 5. 悬浮、移动与调整大小

- **移动**：按住顶部标题文字或空白区域拖动；不要在音标按钮或工具按钮上拖动。
- **调整尺寸**：拖动窗口边缘或角落。空间不足时，音标区域可纵向滚动。
- **置顶**：点击右上角图钉。蓝色背景表示正在置顶。
- **最小化 / 关闭**：点击标题栏的 `—` 或 `×`。

窗口会记住位置、尺寸和置顶状态。如果显示器布局变化导致窗口原位置在屏外，程序会尝试将它移回显示器工作区。

## 6. 迷你模式

![迷你模式界面](images/mini.png)

点击图钉右侧的面板切换按钮，即可进入迷你模式：隐藏示例词，减小按钮和间距，保留搜索、分类、复制格式和滚动。再次点击同一按钮恢复完整模式。两种模式分别保存尺寸。

## 7. 收藏与最近使用

1. 在某个音标上**单击右键**，选择“收藏音标”。
2. 被收藏的音标右上角会出现小星标。
3. 打开“收藏 / 最近”，即可找到收藏与最近复制过的音标。
4. 再次右键选择“取消收藏”可移除收藏。

最近使用最多保留12项，同一条目重复使用会更新顺序。收藏和最近记录会在下次启动后保留。

## 8. 附加符号怎么粘贴

`◌` 是表示附着位置的占位圆圈，不属于实际复制内容。

例如“鼻化符号”展示为 `◌̃`，实际复制的是 **U+0303 COMBINING TILDE**：

1. 在目标程序输入基字 `a`。
2. 点击音标助手中的“鼻化符号”。
3. 回到 `a` 后按 Ctrl+V，得到 `ã`。

送气符号实际复制 `ʰ`，可以粘贴在辅音后，例如 `pʰ`。上下连音弧也不会复制占位圆圈；组合符号如何对齐，取决于目标程序和字体的排版支持。

## 9. 常见情况

**粘贴后显示为方块或位置不理想**  
在目标程序中换用 Cambria、Segoe UI 或 Segoe UI Symbol。软件不要求额外安装第三方字体。

**提示“剪贴板正忙，未复制”**  
等待片刻后再次单击。某些剪贴板管理器、远程桌面或其他程序可能短暂占用剪贴板；未成功时不会显示“已复制”。

**重复双击后没有新窗口**  
这是单实例设计，程序会唤起已有窗口；若已最小化，会尝试恢复。

**设置损坏或想重新开始**  
先关闭软件，将 `%APPDATA%\IPAClipboard\settings.json` 重命名为备份文件，再重新启动。程序会生成默认设置；原收藏可从备份文件中恢复。

**英语为什么写“教材48”**  
这里的48由常用44加 `ts/dz/tr/dr` 四个教学组合构成。四个组合通常不作为四个独立英语音位；集中双元音的读法也可能随口音变化。
